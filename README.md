### Controls:
Arrow keys (or wasd) ***and/or*** mouse (click and drag, pointer direction) </br>
^ There are tips just before the start of the minigame to give some indication of what to do


### Minigames:
- Wire matching
    - Click and drag the alligator clips to the corresponding wire. Once connected the sparks will disappear
- Avoid fatality
    - Don't swallow bugs or osha-uncertified batteries, dodge using movement keys and use the cursor to look away
- "write" code
    - Press the copy and paste buttons (in order) to maintain code output 
- *more coming soon*
