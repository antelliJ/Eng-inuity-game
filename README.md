# Eng-inuity-game
https://github.com/antelliJ/Eng-inuity-game

An engineering themed warioware like game. This means its fastpaced with a collection of microgames to test reaction time and problem solving skills. Each minigame has a new engineering-inspired task, and more challenges are planned in the future.

### Features

- Fast paced engineering themed minigames
- Keyboard and mouse controls
- Playable in the browser
- Unique gameplay mechanics in each minigame
- Custom made assets
- Custom particle/shader action
- Made with Godot 4
- Continued development likely


### How to play

Below is where you can try it out now
[Link to Itch game](https://o7m8.itch.io/enginuity)
It's a web build, so it should launch on most popular OS' and browsers just as easy as clicking 'run game'!
read the instruction before the minigame, complete the objective, and continue to the next minigame

### Controls:
- WASD / Arrows -> movement
- Mouse -> look / interact / drag things
    - Left Click - grab and click things 
</br>
^ There are tips just before the start of the minigame to give some indication of what to do


### Minigames:
- Wire matching
    - Connect the alligator clips to the corresponding wire by click and dragging. Once connected the wires stop sparking 
- Avoid fatality
    - Avoid swallowing bugs or osha-uncertified batteries. Dodge using movement keys and use the cursor to look away
- "write" code
    - Press the copy and paste buttons (in order) to maintain suitable code output 
- *more coming soon*
